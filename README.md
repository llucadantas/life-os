# Life-OS API 🚀

Uma API REST simples desenvolvida como projeto de estudos para gerenciar Usuários e Tarefas. O objetivo deste projeto é colocar em prática conceitos de desenvolvimento back-end, arquitetura REST e estruturação de dados.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **Java**
* **Spring Boot**
* **Spring Web** (para criação dos endpoints REST)
* **Banco de Dados** (PostgreSQL)
